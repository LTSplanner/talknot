# KNOTE 営業ロープレ評価基準（設計思想つき）

住宅リフォーム（ライフタイムサポート）の商談・ロープレを評価するための基準書。
**表面のトークの上手さではなく、「潜在ニーズを引き出し、関係値を築き、受注につなげられたか」**を測る。
他のロープレ判定（人・AI問わず）にもこの文書をそのまま基準として使える。

---

## 0. なぜこの評価をするのか（最上位の思想）

**現場の最大の課題：** プランナーが**お客様の潜在ニーズを引き出す前に商品説明へ進んでしまう**。
その結果、見積書に入れても**後から外されやすい**。
→ だから評価は「説明の流暢さ」ではなく、**説明に入る前の“関係値づくり”と“ニーズの引き出し”**を中心に見る。

**受注につながる商談の型（この評価が推奨する姿）：**
1. まず信頼関係をつくり、なんでも相談される空気にする（＝お客様が本音を漏らし始める）
2. 暮らし・不安・困りごと（潜在ニーズ）を、**お客様自身の言葉で語らせる**（自分ごと化）
3. そのニーズへの**回答として**商品・施工事例を出す（機能の羅列にしない）
4. 粗利の高い重点商材（**コーティング／エコカラット／ダウンライト**）を、
   「自分には必要だ」と納得した状態でご提案する

**大原則（減点の芯）：**
> ニーズの引き出しが不十分なまま説明・見積提示に進んでいたら、
> トークがどれだけ流暢でも高評価にしない。

## 1. 評価の全体構造

| 層 | 内容 | 役割 |
|---|---|---|
| **2つの視点（軸）** | 🎯模範トーク視点／💼営業プロ視点 | 同じ商談を2つの物差しで採点 |
| **5つの評価項目** | ①〜⑤（各1〜5点） | 商談の質を分解して測る |
| **会話配分（ジョハリの窓）** | 開放／盲点／秘密／未知 の時間% | 既知の確認に偏らず提案・本音引き出しに時間を割けたか |
| **隠れたニーズ（秘密領域）** | 非言語から読む本音の検出 | 表面の言葉の“裏”を読めたか |

### 2つの視点（必ず別の物差しで採点する）
- **🎯 模範トーク視点（reference）＝再現度**：登録した模範トークスクリプトの
  「型・流れ・言い回し」をどれだけ**再現**できたか。未登録なら住宅営業の基本の型。
- **💼 営業プロ視点（sales）＝本質的な質**：模範に関係なく、**お客様目線で見た
  トークそのものの完成度**。
- ※この2軸は測るものが違うので、**全項目が同点になるのは不自然**。観点の違いを点数にも反映する。

## 2. 5つの評価項目（見る点・背景・加点／減点）

### ① 追加検討が増えたか　🌱
- **見る点：** 商談を通じてお客様の検討項目・興味が広がり、次の一歩につながったか。
- **背景（なぜ）：** 受注は「1商材で終わり」ではなく、関心の広がり＝見積点数の増加が売上に直結する。
  重点商材（コーティング等）を、お客様が自分から「それも気になる」と言う状態に持っていけたかを見る。
- **加点：** お客様が新たな関心を口にした／「それもお願いしたい」を引き出した。
- **減点：** 聞かれたことに答えるだけで終わった／こちらから可能性を広げられなかった。

### ② 臨機応変に対応ができるか　🤸
- **見る点：** 想定外の質問・反応に、柔軟に切り返せたか。
- **背景：** 台本通りに話せることより、**目の前のお客様に合わせて調整**できることが信頼を生む。
  反論・持ち帰り・比較検討などの“崩し”にどう対応したかが受注の分かれ目。
- **加点：** 断り文句を否定せず受け止め、土俵を変えて再提案できた（例：価格比較→中身比較）。
- **減点：** 想定外で沈黙・パニック／用意した説明に戻してしまい相手の話を置き去りにした。

### ③ お客様の感情をキャッチできているか　💗
- **見る点：** 声のトーン・間・表情から感情の動きを読み、適切に拾えたか。
- **背景：** 人は理屈でなく感情で決める。**不安・警戒・期待の揺れ**を拾って言語化できると、
  お客様は「わかってくれている」と感じ、本音を出しやすくなる。
- **加点：** 相手の迷い・不安を察して一度受け止めた（「ご不安ですよね」等）。
- **減点：** 感情のサインをスルーして説明を続けた／早口・被せで相手の間を潰した。

### ④ お客様の背景を深掘れたか　🔍（最重要に近い）
- **見る点：** 秘密領域（家族構成・実家との距離・子供・引越し時期と年齢・予算の本音など）まで、
  信頼関係を築いて踏み込めたか。
- **背景：** これが**課題の核心**。背景を知らずに出した提案は的外れになり、見積から外される。
  背景を引き出せていれば、提案が“その人のための提案”になり、受注率が上がる。
- **加点：** 暮らし・家族・予算感などの背景を、詰問でなく自然に引き出せた。
- **減点：** 表面の要望だけ聞いて即・商品説明／背景を聞かず一般論の提案に進んだ。

### ⑤ 雰囲気よくワクワクしたか　✨
- **見る点：** 「任せたら理想の家ができる」という期待値が高まり、会話が弾んだか。
- **背景：** 不安の解消だけでなく**前向きな期待**を作れると、価格の壁を越えて決断しやすくなる。
  施工事例やビジュアルで“できあがりの生活”を想像させられたか。
- **加点：** 事例・完成イメージで期待を高めた／会話が双方向で弾んだ。
- **減点：** 事務的・一方通行で、体験や未来像が語られなかった。

## 3. 採点アンカー（1〜5）— 甘くつけない

各項目・各視点を、次の基準で**厳格に**採点する（ニーズ引き出しの深さに連動）。

| 点 | 状態 |
|---|---|
| 1 | お客様の本音・不安をほぼ拾えず、表面的なやり取りに終始 |
| 2 | 一部は拾えたが、肝心の“裏のニーズ”を取りこぼした |
| 3 | 表面ニーズには対応できたが、言葉にされない不安・疑問への踏み込みは不十分（**標準**） |
| 4 | 言葉にされていない不安・疑問を察知し、的確に踏み込めた（明確な根拠がある時のみ） |
| 5 | お客様自身も気づいていなかったニーズまで言語化し、信頼と期待を一段引き上げた（**稀**） |

- **会話が滑らかでも、裏のニーズを取りこぼしていれば高得点にしない。**
- **大半の実商談は2〜3に収まる。** 4〜5は具体的な根拠（タイムスタンプ／発言）がある時だけ。
- 講評（コメント）の言葉は前向き・建設的に。ただし**点数は甘くしない**。

## 4. 会話配分（ジョハリの窓）

商談の会話時間を4領域に配分（合計≒100%）。**開放領域（既知の確認）に偏らず、
盲点（プロの提案）と秘密（本音の引き出し）に時間を割けたか**が質を左右する。

| 領域 | 意味 | 評価上の位置づけ |
|---|---|---|
| 開放（open） | 双方が知っている＝既知の確認・世間話 | ここばかりは価値が低い |
| 盲点（blind） | お客様が気づいていない＝プロの提案・気づきの提供 | **価値創出** |
| 秘密（hidden） | お客様は知っているが我々は知らない＝本音・事情の引き出し | **価値創出** |
| 未知（unknown） | 双方が知らない＝対話で新たに見つかった気づき | 価値創出 |

- **価値創出ゾーン＝盲点＋秘密の合計%が高いほど良い。**
- 背景：カクシン研修（野本さん提案）由来。「時間配分」で商談の質を客観測定するという発想。

---

## 5. 隠れたニーズ（秘密領域）の検出

- **定義：** 非言語サイン（間・言い淀み・話題の回避・過剰な同意・声の小ささ・即答できない様子）から読む、
  **お客様が言葉にしていない不安・疑問・本音**（本人も自覚していないものを含む）。
- **評価：** それに営業が気づいて踏み込めたか（surfaced=true）／表面で流したか（false）。
- 例：予算オーバーへの本当の不安、家族への遠慮、決断を先延ばししたい心理、本当は譲れない条件。

## 6. ロープレの属性別・段階設計

同じトークでも相手の状態で難易度が変わるため、**お客様属性別**に評価フォーカスを変える。

- **検討済み（decided）：** 既に検討・見積取得済み。
  → 既存検討を否定せず、まだ気づいていない観点を足せたか／価格比較の土俵から**中身の比較**へ移せたか。
- **未検討（undecided）：** 必要性を感じていない（**最難関・最重要**）。
  → いきなり商品説明に入っていないか（説明先行は減点）／暮らし・不満を聞き出し、本人に「言わせた」か／
    「それなら必要かも」と本人が納得する流れを作れたか。

- **信頼関係づくりを最重視する単元：** 導入・会社説明・スケジュール説明。
  → 共感・受け止め、「今日は決める場ではない」と伝える、相談しやすいオープンな問い、売り込み感の排除。
- **お客様像（ペルソナ）：** 実際の商談議事録から生成した「第一声・本音・断り文句・口ぐせ」を、
  属性別に台本と評価へ反映（実データ準拠）。

## 8. まだ確定していない基準（今後の追加候補）

- **「8ステップ」実行チェック**：カクシン研修で学んだ8ステップの営業プロセスが商談内で
  実施されているかを、ステップ単位（実施○/×＋根拠）で採点する。
  → 8ステップの正式な各名称が確定したら評価軸に組み込む。
- **成約データとの相関**：評価スコアと実際の受注/失注を突き合わせ、
  「どの挙動が受注に効くか」を検証し、配点を調整する（将来の高度化）。
